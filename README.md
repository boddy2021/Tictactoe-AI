# Tic-Tac-Toe Game

This is a simple Tic-Tac-Toe game built using Python, where you can play against an AI opponent.

### Features:
- **AI opponent**: Play against an intelligent computer that makes strategic moves.
- **Interactive gameplay**: Play by entering your move on the console.
- **Game board display**: The board updates with each move, showing the current state of the game.
- This game was made during an AI curse offered by CS50.

### How to Play:
1. Run the Python script.
2. The game will ask you to chose how you want to play, either as X or either as O.
3. The AI will take its turn and the game will continue until there is a winner or a draw.
